# 云岭智场：基于高原环境数据与 AI 的云南玉昆队主场优势动态分析系统

一个面向足球赛事的**数据分析与机器学习项目**：以中超球队云南玉昆队主场（云南玉溪，海拔约 1650 米）的高原环境为切入点，采集比赛城市的历史天气数据、构造球员比赛数据与海拔/血氧特征，通过统计分析、可视化与 XGBoost 机器学习模型，探究**海拔、气温、湿度等高原环境因素对球员技术指标及球队胜率的影响**，并对球员的高原适应能力进行量化评分。

---

## 一、项目背景

云南玉昆队主场位于云贵高原的玉溪，海拔约 1650 米，明显高于联赛中多数对手所在城市。高原环境具有气压低、含氧量少、空气干燥等特点，可能对球员的跑动距离、传球成功率、射门表现等技术指标产生影响，从而形成"高原主场优势"。

本项目围绕以下问题展开：

1. 不同海拔梯度下，球员各项技术指标呈现怎样的变化规律？
2. 温度、湿度等气象因素与球员技术指标之间存在什么关系？
3. 同一球员在主场（高原）与客场的表现有何差异？如何量化球员的高原适应能力？
4. 能否基于球员表现与环境特征构建机器学习模型预测比赛胜负？海拔对预测胜率有多大影响？

## 四、数据集说明

| 文件 | 行数（约） | 说明 |
| --- | --- | --- |
| `数据集/气候数据/城市数据/*.csv` | 每文件 30 条 | 城市单日级天气：日期、最高/最低气温、天气、风向风级、湿度 |
| `数据集/气候数据/城市天气总表_data.csv` | 1932 条 | 21 个比赛城市 2024 年 3—5 月天气合并总表 |
| `数据集/玉昆队球员模拟数据与比赛海拔数据/玉昆队_大数据.csv` | 330 条 | 30 场比赛、每场 11 名球员的跑动、射门、射正、传球成功率、抢断、评分及比赛城市海拔 |

## 五、快速开始

### 1. 环境要求

- Windows 10/11（中文字体使用系统自带的 **SimHei 黑体**；其他系统见文末"常见问题"）
- Python 3.10 及以上（开发环境为 Python 3.12）

### 2. 安装依赖

在项目根目录下执行：

```bash
pip install -r requirements.txt
```

如官方源较慢，可使用清华镜像：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 运行代码

所有脚本均使用**相对项目根目录的路径**（基于 `pathlib` 自动定位），无需任何手动配置，**克隆后可直接在 PyCharm 中打开运行**。分析类脚本会弹出图表窗口，同时将图表/模型自动保存到 `outputs/` 目录。

> 数据集已随仓库提供，分析与建模脚本（④—⑧）**无需先运行爬虫**即可直接运行。

## 七、特征工程与建模说明

- **气候压力指数**：`平均气温 × 湿度 / 1000 × (海拔/1000)`，综合刻画温湿压的环境负荷；
- **血氧模拟值**：`95 − 海拔/1000 × 5 − 跑动距离 × 0.3`，体现海拔与运动强度叠加下的血氧下降趋势；
- **建模粒度**：将球员级数据按"比赛 ID"聚合为比赛级样本（跑动均值/总量、射门、射正、抢断、评分均值等），加入气温、湿度、海拔、天气、风向等环境特征；
- **模型**：`StandardScaler + OneHotEncoder` 特征预处理流水线 + `XGBClassifier`（含类别不平衡权重），按 8:2 划分训练/测试集，输出准确率、AUC、混淆矩阵与 Top15 特征重要性；
- **高原效应分析**：固定其余特征，仅令海拔在 0—2000 米间变化，观察模型预测胜率的变化曲线。

> 说明：受限于公开渠道难以获得完整真实赛果标签，模型的"胜负"目标变量是依据主场身份与射正数中位数规则构造的**演示标签**，模型结果用于展示完整的机器学习工程流程与高原影响分析思路，准确率数值不代表真实预测能力。

## 八、常见问题（FAQ）

**Q1：运行天气爬虫 `finddata.py` 需要什么？**
需要本机安装 Microsoft Edge 浏览器（驱动由 `webdriver-manager` 自动下载），并可正常访问天气历史网站。若网络环境受限或页面结构调整，可跳过该脚本，仓库已提供抓取好的天气数据。

**Q2：图表中的中文显示为方块怎么办？**
Windows 自带 SimHei 黑体通常可直接显示；macOS/Linux 可将脚本中 `font.sans-serif` 调整为 `Arial Unicode MS`（macOS）或 `WenQuanYi Zen Hei`（Linux），并安装对应中文字体。

**Q3：`outputs/` 目录在哪里？**
运行任意脚本后会在项目根目录自动创建，其中保存中间数据表、PNG 图表和训练好的模型文件；该目录不提交到 Git，删除后重新运行即可再生成。

**Q4：为什么重新运行 `tt.py` 后数据与仓库自带的不一样？**
模拟数据包含随机过程，每次运行都会重新生成一份分布一致但数值不同的数据，属正常现象。
